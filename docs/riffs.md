# Original Riff Exercises

Chordmaster includes short, original guitar exercises composed for this project. They are intended to demonstrate timing, rests, octave-aware notes, and generated playback without reproducing commercially released music.

## Notation

- `s`: sixteenth note
- `e`: eighth note
- `q`: quarter note
- `h`: half note
- `w`: whole note
- `R`: rest

Each event is written as `NOTE+OCTAVE(DURATION)`, for example `E2(e)` or `R(q)`.

The compiled catalog lives in `internal/instruments/guitar/riffs.go`. Additions must be original compositions.
